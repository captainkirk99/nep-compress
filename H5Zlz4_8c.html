Detailed Description

HDF5 filter plugin for LZ4 compression (filter ID 32004).

This file is vendored unchanged from HDF Group hdf5_plugins LZ4/src/H5Zlz4.c at commit 4d6b8cec92 (upstream master); only comments were added. See plugins/README.md for how to update it.

Filter parameters: cd_values[0] is the block size in bytes (0 selects the default of 1 GiB) and cd_values[1] is the encoder selector (0 or 1 for the default fast encoder, a negative value for fast-mode acceleration 1 - value, and a value >= 2 for LZ4HC at that level).

The on-disk chunk encoding is described in the LZ4 HDF5 format page.

The LZ4 filter callback called by the HDF5 library.

Runs in both directions: compression (forward) and decompression (H5Z_FLAG_REVERSE set in flags). The buffer is replaced in place through buf / buf_size.

Parameters
flagsFilter flags; H5Z_FLAG_REVERSE selects decompression.
cd_nelmtsNumber of filter parameters in cd_values.
cd_valuesFilter parameters; cd_values[0] is the block size in bytes (0 for the 1 GiB default) and cd_values[1] is the encoder selector.
nbytesSize in bytes of the input data in buf.
buf_sizeSize in bytes of the buffer pointed to by buf.
bufPointer to the buffer holding the data; on success it is replaced with the filtered buffer.
Returns
The size of the filtered data, or 0 on failure.

Compress one block, selecting the encoder from the filter parameter.

Mirrors liblz4's lz4frame compressionLevel convention: a value >= LZ4HC_CLEVEL_MIN (2) selects LZ4HC at that level, 0 or 1 selects the default fast encoder, and a negative value selects fast mode with acceleration 1 - value.

Parameters

dstPointer to the output buffer.
srcSzSize in bytes of the input block.
dstCapCapacity in bytes of the output buffer.
encoderParamEncoder selector from cd_values[1].
Returns
The number of compressed bytes, or 0 on failure.
