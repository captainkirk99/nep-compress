# V1.2.0 Sprint 2: Spack Support

Source: `docs/roadmap.md`, "V1.2.0 Compression Filter for Meteosat / Sprint 2".

## Goal

nep-compress can be installed with Spack. A `nep-compress` recipe
lives in this repository as a small Spack package repository overlay.
A new CI workflow builds the current checkout through that recipe on
an MPI NetCDF-C stack and runs the full CTest suite plus a Spack
stand-alone test. The same recipe file is submitted to
`spack/spack-packages` as a new package. To make this work with the
NetCDF-C that upstream Spack ships today (4.10.0), nep-compress's
minimum NetCDF-C drops to 4.10.0. The only part that needs 4.10.1, the
zstd-based `perf_compare_filters` test, is switched off automatically
on older NetCDF-C.

  ```python
  # Copyright Spack Project Developers. See COPYRIGHT file for details.
  #
  # SPDX-License-Identifier: (Apache-2.0 OR MIT)

  from spack_repo.builtin.build_systems.cmake import CMakePackage

  from spack.package import *


  class NepCompress(CMakePackage):
      """nep-compress provides additional compression filters for NetCDF-4/HDF5:
      an LZ4 HDF5 filter plugin with C and Fortran APIs, and Fortran wrappers for
      NetCDF-C's BZIP2 filter."""

      homepage = "https://captainkirk99.github.io/nep-compress/"
      url = "https://github.com/captainkirk99/nep-compress/archive/refs/tags/v1.1.0.tar.gz"
      git = "https://github.com/captainkirk99/nep-compress.git"

      maintainers("edhartnett")

      license("MIT", checked_by="edhartnett")

      version("main", branch="main")
      version("1.1.0", sha256="1f55bf23d6fb6552c14d868416f71c194843f5d7c011d7571fedfd64a2a45e1e")

      variant("lz4", default=True, description="Build the LZ4 API and HDF5 filter plugin")
      variant(
          "bzip2",
          default=True,
          description="Build the Fortran BZIP2 API and tests (uses NetCDF-C's BZIP2 plugin)",
      )
      variant("fortran", default=True, description="Build the Fortran wrappers")

      conflicts("~lz4~bzip2", msg="Enable at least one compression filter")

      depends_on("c", type="build")
      depends_on("fortran", type="build", when="+fortran")
      depends_on("cmake@3.18:", type=("build", "test"))
      depends_on("pkgconfig", type=("build", "test"))

      depends_on("netcdf-c@4.10.0:", when="@1.2:")
      depends_on("netcdf-c@4.10.1:", when="@:1.1")
      depends_on("netcdf-c+shared", when="+bzip2")
      depends_on("hdf5@1.14:+hl")
      depends_on("lz4", when="+lz4")
      depends_on("netcdf-fortran", when="+fortran")

      def cmake_args(self):
          spec = self.spec
          plugins = spec["netcdf-c"].prefix.plugins
          args = [
              self.define("CMAKE_INSTALL_LIBDIR", "lib"),
              self.define("BUILD_TESTING", self.run_tests),
              self.define("NEPCOMPRESS_BUILD_DOCS", False),
              self.define_from_variant("NEPCOMPRESS_BUILD_LZ4", "lz4"),
              self.define_from_variant("NEPCOMPRESS_BUILD_BZIP2", "bzip2"),
              self.define_from_variant("NEPCOMPRESS_ENABLE_FORTRAN", "fortran"),
          ]
          if spec.satisfies("+bzip2"):
              args.append(self.define("NEPCOMPRESS_BZIP2_PLUGIN_DIR", plugins))
          if self.run_tests and spec.satisfies("@1.2: ^netcdf-c+shared+zstd"):
              args.append(self.define("NEPCOMPRESS_ZSTD_PLUGIN_DIR", plugins))
          return args

      def setup_run_environment(self, env: EnvironmentModifications) -> None:
          if self.spec.satisfies("+lz4"):
              env.append_path("HDF5_PLUGIN_PATH", self.prefix.lib.plugin)

      @run_after("install")
      def cache_test_sources(self):
          cache_extra_test_sources(self, [join_path("test", "consumer")])

      def test_consumer(self):
          """build and run a CMake consumer of the installed package"""
          src = join_path(self.test_suite.current_test_cache_dir, "test", "consumer")
          cmake = which(self.spec["cmake"].prefix.bin.cmake)
          prefixes = [self.prefix, self.spec["netcdf-c"].prefix]
          if self.spec.satisfies("+fortran"):
              prefixes.append(self.spec["netcdf-fortran"].prefix)
          cmake(
              "-S",
              src,
              "-B",
              "build",
              "-DCMAKE_PREFIX_PATH={0}".format(";".join(str(p) for p in prefixes)),
          )
          cmake("--build", "build")
          which(join_path("build", "consumer_c"))()
          if self.spec.satisfies("+fortran"):
              which(join_path("build", "consumer_fortran"))()
  ```

- Tricky cases:
  - `main` sorts above every numbered version in Spack, so `@1.2:`
    covers `main` and future 1.2.x, and `@:1.1` covers only 1.1.0.
  - Never set `NEPCOMPRESS_BUILD_JPEGLS`. It defaults to OFF, and 1.1.0
    does not have it.
  - With `BUILD_TESTING=OFF` (a normal install) and `+bzip2`, CMake
    still runs the BZIP2 plugin probe against NetCDF-C's `plugins`
    directory. That is intended: a broken plugin directory fails at
    configure. `netcdf-c+shared` guarantees that NetCDF-C built its
    plugins.
  - The zstd directory is passed only when tests run, and only for
    `@1.2:` (where the item-1 CMake gate drops it again on NetCDF-C
    older than 4.10.1, exercising the gate in CI). It is never passed
    for `@:1.1`, which has no gate and would run the test against the
    buggy 4.10.0 zstd plugin.
  - `CMAKE_INSTALL_LIBDIR=lib` keeps the plugin at `lib/plugin` on
    distributions where GNUInstallDirs would choose `lib64`, so
    `setup_run_environment` and the docs are right everywhere.
  - The stand-alone test uses `test/consumer` from the installed
    package's test cache. With 1.1.0, that directory still has
    `LANGUAGES C Fortran`, so `spack test run` for `nep-compress@1.1.0~fortran`
    needs a Fortran compiler. This is documented in the PR description,
    not patched.
  - Pass `ruff` / `spack style`: line length 99, no unused imports.
    `EnvironmentModifications`, `cache_extra_test_sources`, `which`,
    `join_path` and `run_after` all come from `spack.package`.

### 4. Spack CI

New `spack/ci/spack.yaml` (the CI environment; the develop path is

```yaml
spack:
  specs:
  - nep-compress@main +lz4 +bzip2 +fortran ^netcdf-c+mpi ^mpich
```

New `.github/workflows/spack.yml`:

```yaml
name: Spack package

on:
  push:
  pull_request:
  workflow_dispatch:

jobs:
  spack:
    runs-on: ubuntu-latest
    name: spack
    steps:
      - uses: actions/checkout@v4

      - name: Set up Spack
        uses: spack/setup-spack@v3
        with:
          spack_ref: v1.2.2
          packages_ref: v2026.10.0
          buildcache: true

      - name: Concretize
        shell: spack-bash {0}
        run: |
          set -euo pipefail
          spack compiler find
          spack -e spack/ci concretize -f
          spack -e spack/ci find -c

      - name: Restore dependency cache
        id: deps-cache
        uses: actions/cache/restore@v4
        with:
          path: /opt/spack
          key: spack-deps-${{ hashFiles('spack/ci/spack.lock') }}
          restore-keys: spack-deps-

      - name: Install dependencies
        shell: spack-bash {0}
        run: spack -e spack/ci install --fail-fast --only dependencies

      - name: Save dependency cache
        if: steps.deps-cache.outputs.cache-hit != 'true'
        uses: actions/cache/save@v4
        with:
          path: /opt/spack
          key: spack-deps-${{ hashFiles('spack/ci/spack.lock') }}

      - name: Build and test nep-compress
        shell: spack-bash {0}
        run: |
          set -euo pipefail
          spack -e spack/ci install --test=root --verbose nep-compress
          prefix="$(spack -e spack/ci location -i nep-compress)"
          log="${prefix}/.spack/spack-build-out.txt.gz"
          test -f "${prefix}/lib/plugin/libh5lz4.so"
          zgrep -q 'tst_lz4_filters' "${log}"
          zgrep -q 'ftst_nep_bzip2' "${log}"
          zgrep -q 'skipping perf_compare_filters' "${log}"
          spack -e spack/ci test run nep-compress

      - name: Upload Spack logs
        if: failure()
        uses: actions/upload-artifact@v4
        with:
          name: spack-logs
          path: |
            /opt/spack/**/.spack/spack-build-*.txt*
            /tmp/**/spack-stage/**/spack-build-*.txt*
```

- Tricky cases:
  - `spack.lock` is created by the concretize step, so `hashFiles` in
    the later steps sees it. The cache is saved **before** nep-compress
    is installed, so a restored cache never contains a stale
    nep-compress that would skip the build and its tests.
  - The `perf_compare_filters` grep checks the 4.10.0 gate from item 1:
    upstream NetCDF-C is 4.10.0, so the status message must be in the
    build log. Spack 1.2.2 stores the build log gzipped at
    `<prefix>/.spack/spack-build-out.txt.gz`, hence `zgrep`. When #6569 merges and `packages_ref` is bumped past it,
    this line changes to `grep -q 'perf_compare_filters'` on the CTest
    output and the comment explains why. That bump is not part of this
    sprint.
  - Whether the buildcache's `hdf5+mpi ^mpich` is reused depends on
    the pinned recipe hashes and compilers. If it is not reused, the
    first run builds HDF5 from source and later runs use the
    `actions/cache` copy. Either result is acceptable. Do not add
    `reuse` or compiler pins to force it.
  - Paths: whether `repos:` and `develop: path:` are resolved relative
    to the environment directory in Spack 1.2.2 is to be confirmed on
    the first run. If they are not, use `${GITHUB_WORKSPACE}`-relative
    absolute paths via `spack -e spack/ci repo add` and
    `spack -e spack/ci develop --no-clone --path "${GITHUB_WORKSPACE}" nep-compress@=main`
    in the Concretize step, and drop those keys from `spack.yaml`. No
    other fallback.
  - MPI: if the build fails because `mpi.h` is not found when the
    tests include `hdf5.h`, the fix goes in nep-compress's
    `CMakeLists.txt` (add `${HDF5_INCLUDE_DIRS}` handling or
    `find_package(MPI)` when `HDF5_IS_PARALLEL`), not in the recipe.
    Record what was needed in the PR description.
