# V1.1.0 Sprint 3: Compression Performance Example

Source: `docs/roadmap.md`, "V1.1.0 - Documentation / Sprint 3".

## Goal

nep-compress ships a fully Doxygen-documented performance program that
runs under `ctest` (`make test`). The program compresses real GFS
surface data with every lossless filter available to NetCDF-4: none,
deflate, szip, zstandard, bzip2 and LZ4, each with shuffle off and on.
It times the complete write (create, define, write, close) and the
complete read (open, read, close), checks that every round trip is
bit-exact, and reports file size, ratio and timings as CSV and as a
readable table. A small zstd-compressed sample of a real GDAS file is
committed under `test/data`. A reference run from the development
machine is committed and summarized on the Doxygen mainpage, replacing
the current "coming in a later release" note.

All other tests keep Sprint 2's one-directory-per-filter rule. (Ed: 3a) |

| Published results | Commit `performance/reference_results.csv` and `performance/reference_machine.txt` from a run on the development machine. Summarize them in a table on the mainpage and link them from `docs/compression.md`. (Ed: 4a) |

- Source data `/home/ed/Downloads/gdas.t00z.sfcf003.nc` (275 MB,
  netCDF-4 classic model, written by NetCDF 4.7.4 / HDF5 1.10.6) has
  dims `grid_xt = 1536`, `grid_yt = 768` and `time = UNLIMITED (1)`.
  It has 148 `float(time, grid_yt, grid_xt)` fields, all with
  `_ChunkSizes = 1, 768, 1536`, shuffle, deflate 1 and
  `_FillValue = 9.99e+20f`. Each field is 4,718,592 bytes
  uncompressed. Sizes as single-field files (uncompressed / deflate 1
  + shuffle): `tmp2m` 4.75 MB / 2.52 MB, `prate_ave` 4.75 / 3.38,
  `soilw1` 4.75 / 0.88, `land` 4.75 / 0.10.
- Sample creation was checked with the installed `nccopy`
  (NetCDF-C 4.10.2-development) and
  `HDF5_PLUGIN_PATH=<dir with only lib__nch5zstd.so>`:
  - `nccopy -F "*,32015,L"` and `-F` together with `-d 0` silently
    applied no filter, and plain `-F` on the original file kept the
    source deflate. A two-step copy works: first
    `nccopy -k nc4 -d 0 -V ...` to an uncompressed file, then
    `nccopy -F "tmp2m&prate_ave&soilw1&land,2|32015,19"`.
  - The result is 6,420,089 bytes, with `_Shuffle = "true"` and
    `_Filter = "32015,19"`. Without shuffle it is 7,897,026 bytes.
  - The plain `-s` flag does not add shuffle without deflate.
    Shuffle must be given as filter `2` in the chain.
- Local NetCDF-C (`/usr/local/netcdf-c`, `netcdf_meta.h`):
  `NC_HAS_SZIP 1`, `NC_HAS_ZSTD 1`, `NC_HAS_BZ2 1`, `NC_HAS_BLOSC 0`.
  `netcdf_filter.h` defines `H5Z_FILTER_DEFLATE 1`,
  `H5Z_FILTER_SHUFFLE 2`, `H5Z_FILTER_SZIP 4`, `H5Z_FILTER_BZIP2 307`,
  `H5Z_FILTER_ZSTD 32015`, `H5Z_FILTER_BLOSC 32001`.
  `nep_compress.h` defines `LZ4_ID 32004` and declares `nc_def_var_lz4`
  unconditionally. Its definition is compiled only with
  `NEPCOMPRESS_BUILD_LZ4`.
- The only local zstd plugin is
  `/usr/local/netcdf-c/hdf5/lib/plugin/lib__nch5zstd.so`. That
  directory also has two ID 307 providers and an HDF Group ID 32004

**Constants and types:**

```c
#define NFIELDS 4
#define NY 768
#define NX 1536
#define NVALS ((size_t)NY * NX)
#define FIELD_BYTES ((double)NVALS * sizeof(float))
#define NREPS 3
#define TMP_FILE "perf_tmp.nc"
#define SZIP_PPB 32

static const char *FIELDS[NFIELDS] = {"tmp2m", "prate_ave", "soilw1", "land"};

/** One filter configuration. */
typedef struct filter_config {
    const char *name;   /* "none", "deflate", "szip", "zstd", "bzip2", "lz4" */
    unsigned int id;    /* 0 for none, else HDF5 filter ID */
    int level;          /* filter level; pixels per block for szip; 0 for none */
} filter_config;

static const filter_config CONFIGS[] = {
    {"none", 0, 0},
    {"deflate", H5Z_FILTER_DEFLATE, 1}, {"deflate", H5Z_FILTER_DEFLATE, 5},
    {"deflate", H5Z_FILTER_DEFLATE, 9},
    {"szip", H5Z_FILTER_SZIP, SZIP_PPB},
    {"zstd", H5Z_FILTER_ZSTD, 1}, {"zstd", H5Z_FILTER_ZSTD, 3},
    {"zstd", H5Z_FILTER_ZSTD, 9}, {"zstd", H5Z_FILTER_ZSTD, 19},
    {"bzip2", H5Z_FILTER_BZIP2, 1}, {"bzip2", H5Z_FILTER_BZIP2, 9},
#ifdef NEPCOMPRESS_BUILD_LZ4
    {"lz4", LZ4_ID, 1}, {"lz4", LZ4_ID, 9},
#endif
};
```

Use Doxygen `/**< ... */` member docs in place of the plain comments
shown above. LZ4 rows exist only when nep-compress's LZ4 is built, so
the program never measures another provider's 32004.

**Functions (all `static` except `main`):**

- `double get_time(void)`: `clock_gettime(CLOCK_MONOTONIC, ...)`,
  returned in seconds. Define `_POSIX_C_SOURCE 200809L` before any
  include.
- `int read_sample(const char *path, float *data[NFIELDS])`: opens the
  sample with `NC_NOWRITE` and reads each field with
  `nc_get_var_float` into a `malloc`ed `NVALS` buffer. On
  `NC_ENOFILTER` it prints
  `"cannot read %s: zstd (32015) plugin not on HDF5_PLUGIN_PATH"` and
  returns 1. It also checks that each field has 3 dims with lengths
  1, `NY`, `NX` and returns 1 otherwise.
- `int filter_available(unsigned int id)`: returns 1 for `id == 0` or
  deflate. Otherwise it creates `TMP_FILE` (`NC_NETCDF4|NC_CLOBBER`),
  calls `nc_inq_filter_avail`, closes and removes the file, and returns
  1 on `NC_NOERR`.
- `int define_filters(int ncid, int varid, const filter_config *c, int shuffle)`:
  - `none`: `if (shuffle) nc_def_var_deflate(ncid, varid, 1, 0, 0)`.
  - deflate: `nc_def_var_deflate(ncid, varid, shuffle, 1, c->level)`.
  - Every other filter: shuffle first, as for `none`, then:
    - szip: `nc_def_var_szip(ncid, varid, NC_SZIP_NN, c->level)`.
    - zstd: `unsigned int p = (unsigned int)c->level; nc_def_var_filter(ncid, varid, H5Z_FILTER_ZSTD, 1, &p)`.
      Use the generic call on purpose, because `nc_def_var_zstandard`
      silently does nothing when NetCDF-C lacks zstd. Say so in the
      doc block.
    - bzip2: `nc_def_var_bzip2(ncid, varid, c->level)` (NetCDF-C's).
    - lz4: `nc_def_var_lz4(ncid, varid, c->level)`.
  - Returns the NetCDF error code.
- `int write_file(const float *data, const filter_config *c, int shuffle, double *secs)`:
  - Timed from before `nc_create(TMP_FILE, NC_NETCDF4|NC_CLOBBER)`
    until after `nc_close`.
  - Inside the timed region: dims `time` = 1, `grid_yt` = `NY`,
    `grid_xt` = `NX` (fixed, not unlimited); var `data`, `NC_FLOAT`;
    `nc_def_var_chunking` with `{1, NY, NX}` (same as the source
    file); `nc_def_var_fill(ncid, varid, NC_NOFILL, NULL)`;
    `define_filters`; `nc_enddef`; `nc_put_var_float`; `nc_close`.
- `int read_file(float *out, double *secs)`: timed from before
  `nc_open(TMP_FILE, NC_NOWRITE)` until after `nc_close`, including
  `nc_inq_varid(ncid, "data", ...)` and `nc_get_var_float`.
- `int verify_file(const filter_config *c, int shuffle)`: runs
  untimed. It reopens the file, calls `nc_inq_var_filter_ids` twice
  (count first, then a buffer of that size), and expects:
  - `none`: no IDs without shuffle; exactly `{2}` with shuffle.
  - deflate: `{1}` without shuffle; `{2, 1}` with shuffle.
  - Other filters: `{c->id}` without shuffle; `{2, c->id}` with
    shuffle.

  On a mismatch it prints the actual list to stderr and returns 1.
- `int run_one(FILE *csv, int field, const float *data, float *buf, const filter_config *c, int shuffle)`:
  - Repeats `NREPS` times: `write_file`, then `read_file` into `buf`,
    then `verify_file`, then
    `memcmp(data, buf, NVALS * sizeof(float))`.
  - Any failure prints field, filter, level and shuffle to stderr and
    returns 1. Keep the minimum write and read seconds.
  - After the loop, `stat(TMP_FILE)` gives `file_bytes`. Then
    `remove(TMP_FILE)`.
  - Writes the CSV row and prints the table row.
  - On the first LZ4 run (`c->id == LZ4_ID`, inside
    `#ifdef NEPCOMPRESS_BUILD_LZ4`), calls
    `nep_check_lz4_provider(NEP_LZ4_PLUGIN_DIR)` after the first
    `write_file` and returns 1 if it fails. Track this with a static
    `int lz4_checked`.
- `int main(int argc, char **argv)`:
  1. Check the arguments.
  2. `read_sample`.
  3. For each distinct filter ID in `CONFIGS`, call
     `filter_available` once and cache the result. For each
     unavailable one, print `# skipped <name>: filter <id> not available`
     to stdout.
  4. `fopen` the CSV and write the header.
  5. Print the table header.
  6. Loop over fields, then configs (skip unavailable), then shuffle 0
     and 1, calling `run_one`.
  7. Free buffers, close the CSV, return 0. Return 1 on any failure.

**CSV** (`%.6f` for seconds, `%.3f` for ratio and MB/s):

```
field,filter,filter_id,level,shuffle,uncompressed_bytes,file_bytes,ratio,write_s,read_s,write_MBps,read_MBps
```

- `ratio = FIELD_BYTES / file_bytes`.
- `MBps = FIELD_BYTES / 1e6 / secs`.
- For szip, `level` is the pixels per block (32).
- The doc block says `file_bytes` is the whole file from `stat()`, so
  it includes a few KB of HDF5 metadata. The `none` row shows that
  overhead.

**Table on stdout**: one block per field, headed `== <field> ==`.
Fixed-width columns: filter, level, shuffle, ratio, write MB/s, read
MB/s. Printed with `printf("%-8s %5d %7d %8.2f %10.1f %10.1f\n", ...)`.

**Runtime:** 4 fields × 13 configs × 2 × 3 repetitions of 4.7 MB. zstd
19 and bzip2 9 dominate. Expect about a minute locally and more under
ASan, so `TIMEOUT 900`. If the local run takes more than 3 minutes,
lower `NREPS` to 2 and report that. Do not drop configurations.

## Out of scope

- Lossy comparisons (quantize with BitGroom, GranularBR or BitRound
  plus a lossless filter). Not planned.
- Blosc (32001) and other hdf5plugin filters (Bitshuffle, Blosc2, SZ,
  Zfp, ...). Not planned; local NetCDF-C has `NC_HAS_BLOSC 0`.
- Asserting ratio or speed thresholds in tests. Not planned, because
  results depend on the machine.
- Plotting scripts for the new CSV. Not planned.
- Changing or converting `examples/performance` (manual synthetic-data
  benchmarks). Unchanged.
- Windows/macOS plugin-path separators for the performance test.
  Unix-only, like the rest of the test suite.
- Per-variable storage size via HDF5 `H5Dget_storage_size`. The program
  uses `stat()` file size, as the book examples do.
- JPEG-LS / `H5ZJPEGLS` (V1.2.0). Note for that sprint: hdf5plugin
  lists `FciDecomp`, the EUMETSAT JPEG-LS filter, among its filters.
