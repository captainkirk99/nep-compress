# V1.3.0 Sprint 1: Redo Graphs with Fixed LZ4 Filter

Source: docs/roadmap.md, "V1.3.0 Include JPEG-LS Filter Code / Sprint 1".

## Goal

The published performance results come from a run made with the
vendored HDF Group LZ4 plugin that ships in nep-compress 1.2.0. That
the right plugin was used is proven by its path and checksum, not
assumed. The zstd and BZIP2 plugins used in the run link the same
HDF5 2.1.1 as NetCDF-C. The reference CSV, the machine record, the
four graphs and every number and claim drawn from them in the docs
come from that one run. The docs say when it was made, with which
nep-compress version, and with which versions of every library
involved. Old LZ4 plugin builds are gone from this machine, so later
work cannot pick them up by accident, and the installed NetCDF-C
plugins are fixed for later work too. After the run, main moves to
version 1.3.0.
