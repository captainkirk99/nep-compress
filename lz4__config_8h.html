Detailed Description

Configuration shim for the LZ4 HDF5 plugin.

Defines the platform feature macros that H5Zlz4.c expects from an autotools-style config.h, so the plugin builds under CMake without generated headers.

Author
Edward Hartnett, Intelligent Data Design, Inc.
